You are an expert full-stack software engineer and UI/UX designer.

I have an existing Python project called "Code Quality Analyzer". The backend logic already exists in Python and must NOT be rewritten. Your job is to transform it into a modern, production-ready web application while preserving and reusing the existing analyzer modules.

=====================================================
PROJECT OVERVIEW
=====================================================

The application analyzes Python projects and reports code quality metrics.

Current analyzer modules:

- scanner.py
  Recursively scans a project directory and finds all Python (.py) files.

- parser.py
  Parses Python files using Python's Abstract Syntax Tree (AST).

- long_function.py
  Detects functions exceeding a configurable number of lines.

- complexity.py
  Calculates Cyclomatic Complexity.

- maintainability.py
  Calculates a maintainability score.

- duplication.py
  Detects duplicate functions.

- report.py
  Generates formatted analysis reports.

The existing analyzer is fully functional and must remain the core engine.

Do NOT rewrite these modules.

Instead, build a complete website around them.
